ABOUT

Street energy meets compiler theory.

What it is

YoungStunna Code is a mini compiler/interpreter project built in Python and deployed through Flask. It accepts source code, checks validity, and executes correct programs in the browser.

What it demonstrates

The project covers the major phases of language processing: tokenization, parsing, semantic validation, and program execution.
