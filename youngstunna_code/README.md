# YoungStunna Code

YoungStunna Code is a custom mini compiler/interpreter inspired by Filipino Gen Z and Young Stunna vocabulary.

## Keywords
- `safe` = variable declaration
- `sah` = input
- `ebas` = output

## Features
- Variable declaration
- Assignment
- Integer numbers
- Input and output
- Arithmetic expressions
- Comments using `/* */`
- Semicolon at the end of each statement
- Syntax checking
- Semantic checking
- Program interpretation

## Example Program
```ysc
safe p;
safe roksi;
p = 10;
roksi = p + 5;
ebas roksi;
